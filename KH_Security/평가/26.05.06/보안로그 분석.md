## 문제 1. 시스템 로그 정보를 확인

### 문제 1-1. 로그인, 장치 구동, 시스템 설정, 파일 시스템 작동,등 다양한 로그 정보를 파일로 부터 최근 10항목 내외로 확인하세요.
```text
tail -n 10 /var/log/messages
```

### 문제 	1-2. ssh, telnet등의 원격 접속 관련 로그 정보를 파일로 부터 최근 10항목 내외로 확인하세요  
```text
tail -n 10 /var/log/secure
```

### 문제 1-3. 현재 로그인된 사용자에 대한 정보는 어떤 로그 파일이 저장되는지 기술하세요
```text
/var/log/utmp
```

### 문제 1-4. 계정의 로그인, 재부팅에 대한 정보는 어떤 로그 파일이 저장되는지 기술하세요.
```text
/var/log/wtmp
```

## 문제 2. 로그 시스템을 관리

### 문제 2-1. systemd 시스템의 핵심 구성 요소로 시스템 로그를 중앙 집중적으로 관리하고 시스템, 커널, 서비스, 애플리케이션 등에서 발생한 로그를 수집하고 저장해주는 것은 무엇인가?
```text
systemd-journald
```

### 문제 2-2. journald의 휘발성 로그 정보가 저장되는 위치는 어디인가?
```text
/run/log/journal/
```

### 문제 2-3. SystemMaxUse와 RuntimeMaxUse의 차이를 설명하세요.
```text
둘다 저장 가능한 로그의 최대 용량이지만 SystemMaxUse는 영구적인 로그의 최대 저장 용량이고 RuntimeMaxUse 휘발성 로그의 최대 저장 용량이다.
```

## 문제 3. journalctl을 이용해서 로그정보를 조회

### 문제 3-1. cron 관련 로그 정보를 조회한다.
```text
journalctl -u crond
```

### 문제 3-2. root 관리자 관련 로그 정보를 조회한다.
```text
journalctl _UID=0
```

### 문제 3-2. 실시간 부팅 횟수를 확인한다.
```text
journalctl --list-boots
```
